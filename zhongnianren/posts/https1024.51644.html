以前一直觉得终端能跑命令就行，Alacritty、Ghostty、Kitty 这些性能都够用，压根没想过要换。🖥️
直到有次远程调试到一半，笔记本没电自动关机，重新开机后，之前连着的五六个 SSH 和 agent 会全没了。tmux 虽然能恢复，但每个 pane 的目录、环境变量都得重搞一遍，烦得很。
后来试了下 tty7，Rust 写的，基于 Zed 的 gpui 做渲染，VT 内核来自 Alacritty。
退出应用或重启后，shell 和已支持的 agent 会确实能接着跑，不用再靠 tmux。
输入方面有历史建议、智能补全、语法高亮、模糊搜索历史。SSH 原生支持 SFTP、端口转发、跳板机，对 Claude Code、Codex 这类 agent 会显示状态、通知、git 上下文。
远程工作区的文件、仓库、pane 都留在远端，换台机器重连能接着干活。
传送门 https://github.com/l0ng-ai/tty7
