一个 Neovim 插件，读你本地 Cursor 的登录信息，直接连 Cursor 的私有 API 拿补全结果。支持多行 ghost text、差异改写、以及连续按 Tab 跳转到下一个编辑位置。
不需要 API Key 或额外注册，装好 lazy.nvim 指定 repo 就能用。Python sidecar 通过 uv 管理依赖，不污染系统 Python。macOS、Linux、Windows 都能跑，前提是装了 Cursor Desktop 并登录过。
https://github.com/teocns/neocursor.nvim
