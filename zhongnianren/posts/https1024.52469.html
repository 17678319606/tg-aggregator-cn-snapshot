推荐一个很有潜力的开源下载神器：FluxDown，直接冲着“免费开源 IDM 平替”来的。
它用 Rust + Tokio 做下载引擎，支持 HTTP/HTTPS、FTP、磁力/BT、eD2K、HLS、DASH，还有动态分段加速和断点续传。Chrome、Edge、Firefox 也能装扩展直接接管下载。
更骚的是它内置 MCP Server，Claude、Cursor 等 Agent 可以直接帮你添加、查看和控制下载任务。Windows、macOS、Linux、Android、NAS / Docker 都覆盖了。
IDM 要钱、又主要是 Windows；FluxDown 免费开源，还把 BT、流媒体和 AI Agent 一起塞进来了。
⁠GitHub：https://github.com/zerx-lab/FluxDown
⁠在线官网：https://fluxdown.zerx.dev/zh/
