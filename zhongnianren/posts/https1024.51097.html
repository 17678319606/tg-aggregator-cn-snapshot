AI Agent 终于能直接用你的浏览器了。
腾讯最近开源的 BrowserSkill，最大的特点就是：不用重新登录，直接复用浏览器现有登录状态。
🤖 Claude Code / Cursor / Codex 都能接
🖥️ 专属 Agent Window，和日常浏览互不干扰
🔌 CLI → 本地守护进程 → 浏览器扩展
🛑 遇到验证码、登录等操作会暂停让你接管
Chrome、Edge，Windows / macOS / Linux 都支持。
简单说，就是给 Agent 接上了一双真正能干活的“浏览器手”。
目前项目采用 MIT 协议开源。
https://github.com/Tencent/BrowserSkill
