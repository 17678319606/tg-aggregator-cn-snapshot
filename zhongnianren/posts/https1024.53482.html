如果你平时用 S3 + CloudFront 部署静态网站或前端资源，传完文件后还要检查 Header、改 Metadata、再去 CloudFront 清缓存，来回切 AWS Console 会有点耗时间。
Hoistbay 是一款免费开源的 S3 客户端，支持 macOS 和 Windows。
它不只是管理 Amazon S3 文件，还能按规则自动设置 Cache-Control / Content-Type，修改 Metadata，并直接创建 CloudFront Invalidation。
比较适合还在手动处理这套发布流程的用户。
而且 AWS 密钥保存在系统安全存储中，没有自建后台和遥测。
