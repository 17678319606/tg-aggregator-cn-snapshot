MediaGo 是一款跨平台开源视频下载器，支持 M3U8 / HLS 资源提取，也把 yt-dlp、N_m3u8DL-RE、BBDown、aria2 这些工具整到了一套界面里。
支持 Windows、macOS、Linux，还能用 Docker 部署到 NAS 或服务器，通过 Web UI 跨设备管理下载任务。
比较有意思的是它还提供 HTTP API 和 OpenClaw Skill，可以让 Claude Code、Cursor 这类 AI Agent 直接把任务交给 MediaGo 处理。
平时要处理自己保存的 M3U8 / HLS 资源，又不想每次开终端敲 yt-dlp，可以看看它。
