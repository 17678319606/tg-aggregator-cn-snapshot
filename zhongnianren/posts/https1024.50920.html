一个终端里的开发工作区,把模态编辑器、文件管理、终端复用、Git 和可分离的持久会全装进同一界面。
https://github.com/runyte/runyte
Runyte 是 Rust 写的终端编辑器兼工作区,主打模态编辑,selection-first 加多重光标,按键风格像 Helix,Vim 的常用动作也有别名。
文件浏览器、终端会、Git 和语言工具不是各自为政的插件,共用同一批面板、命令和主:Tab 切换、一处剪贴板、什么都能模糊搜索,还能在不同 Git worktree 之间跳转。
