SimulTeX 把 Codex CLI 和 Claude Code 跑起来的会镜像到本地 localhost 的页面，终端键盘输入不动，浏览器只跟着看。
它还起一层 loopback 反向代理，把模型 API 的往返归一化成 turn、调用、用户消息这几类事件，靠它保住精确的 Markdown 和 LaTeX，API 拿不到的启动信息、状态条、权限面板由 PTY 重构补。
