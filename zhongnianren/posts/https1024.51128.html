原来现在做 OSINT，已经可以把这么多公开数据塞进一张 3D 地球里了。
最近挖到一个开源项目 OSIRIS，打开浏览器就是一套实时情报大屏。
🌍 航班、卫星、海事、地震、野火实时汇总
📹 全球公开 CCTV 数据统一查看
🔥 NASA 火点、天气、冲突区域一张图掌握
🛰️ 还有新闻流、网络威胁、DNS / WHOIS 等 OSINT 工具
⚡ WebGL GPU 渲染，数据多了也能流畅展示
🐳 支持 Docker 自托管，核心数据源无需 API Key
更有意思的是，它不是单纯做个炫酷地图，而是把一堆公开数据源真正整合到了一个界面里。
做 OSINT、新闻核查、安全研究，甚至单纯喜欢研究全球实时数据的，都可以玩玩。
🔗 https://github.com/simplifaisoul/osiris
