一个挺有潜力的开源下载神器：FluxDown，摆明了要做免费开源的 IDM 平替。
引擎是 Rust + Tokio，HTTP/HTTPS、FTP、磁力/BT、eD2K、HLS、DASH 都吃，还带动态分段加速和断点续传。Chrome、Edge、Firefox 装个扩展就能接管下载。
更狠的是内置 MCP Server，Claude、Cursor 这类 Agent 能直接帮你加、查、控下载任务。Windows、macOS、Linux、Android、NAS / Docker 全覆盖。
IDM 要钱还只吃 Windows；FluxDown 免费开源，把 BT、流媒体和 AI Agent 一起塞进来了。
⁠GitHub：https://github.com/zerx-lab/FluxDown
⁠在线官网：https://fluxdown.zerx.dev/zh/
