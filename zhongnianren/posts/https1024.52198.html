想自己做量化交易，最麻烦的往往不是写策略，而是工具东拼西凑。
这 6 个 GitHub 项目，基本能把学习 → 策略 → 回测 → 实盘接口串起来：
1️⃣ awesome-quant：量化工具总目录，数据、回测、风控、交易库一网打尽
https://github.com/wilsonfreitas/awesome-quant
2️⃣ machine-learning-for-trading：机器学习量化经典教程，27 章配套 Notebook，从数据一路做到策略
https://github.com/stefan-jansen/machine-learning-for-trading
3️⃣ quant-trading：现成策略库，配对交易、统计套利、MACD、布林带等直接参考
https://github.com/je-suis-tm/quant-trading
4️⃣ backtrader：Python 经典回测框架，策略先拿历史数据跑，别急着拿真钱试
https://github.com/mementum/backtrader
5️⃣ zipline：Quantopian 当年的回测引擎，研究事件驱动回测很有参考价值
https://github.com/quantopian/zipline
6️⃣ ccxt：加密货币量化常用库，用一套 API 对接大量交易所
先学别人怎么做，再写策略，最后回测验证。别把“会写代码”和“能赚钱”当成一回事。
