这是我见过最完整的「一个人公司」教程
GitHub 上有个很值得收藏的项目——
One Person Businesses Methodology
一句概括：
教你一个人做一家公司。
很多人做副业的问其实不是技术，而是：
不知道做什么
不知道怎么赚钱
不知道怎么长期做下去。
这套方法论最厉害的一点是：
几乎不讲虚的。
作者像写代码一样，把一人公司拆成完整流程：
发现需求 → 做 MVP → 获取流量 → 完成变现闭环
看完会有种感觉：
这不是教程，更像一套商业操作系统。
尤其是 v2.0 里提到的一些反直觉认知，比如：
与其只看收入，
不如看 税后收益。
与其拼命提高效率，
不如 用 AI 杠杆放大个人产出。
核心理念：
一人企业的目标不是做大，而是做稳。
