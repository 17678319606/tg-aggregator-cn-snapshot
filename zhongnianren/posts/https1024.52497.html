把锁在翻页阅读器里无法复制文字的扫描书、幻灯片或 PDF 批量变成文本——框选一次区域后按快捷键逐页截图 OCR，或让扩展自动翻页跑完整本书，全程离线。
https://github.com/thiagotigaz/ocr-it
装上这个 Chrome 扩展后，先用 ⌥⇧R 在页面上拖个框，然后每按一次 ⌥⇧S 它就截下这块区域丢给本地 Tesseract 识别，文字按页攒着；懒得手动按就 ⌥⇧A 一键托管，它自己截图、自己翻页，跑到文档末尾自动停。识别完全离线，扩展一个出站请求都不发，也不用 API key。
