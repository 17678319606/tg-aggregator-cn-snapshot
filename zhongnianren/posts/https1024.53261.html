GitHub 上还在一处处翻免费代理节点？有人干脆做了个自动挖节点的工具！
开源项目 ProxyNodeHub 值得一推，专盯 GitHub 上那些活跃的免费节点仓库。
最省心的是，点一下「搜索并分析」，它就能自动筛仓库、看更新频率、提取订阅链接，再把散落各处的节点合并去重，一键导出。
从前找节点得手动翻仓库，如今工具直接替你挖。
眼下支持 Windows 10/11，免费开源。公共节点的隐私和稳定性没法保证，建议只当备用。
GitHub：https://github.com/wanvfx/ProxyNodeHub
