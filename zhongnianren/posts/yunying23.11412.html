一部手机完成美区 AppleID 注册
1️⃣ 进入 Apple ID 注册页
名字随便填，国家选「United States」
邮箱用没注册过的
密码 ≥ 8位（含大小写+数字）
手机号直接用国内号码就行。
验证码一填——注册完成✅
2️⃣ 打开 App Store 登录刚注册的账号
随便下载一个 App
系统弹出提示：「此 Apple ID 尚未在 iTunes 商店使用过」
→ 点击“检查”
→ 选择「United States」
→ 下一步
🔍 然后打开浏览器，搜索 “US Address Generator”
生成一个免税州的地址（推荐：Oregon / Alaska / Delaware / Montana / New Hampshire）
付款方式选「None」
地址填入即可通过💫
