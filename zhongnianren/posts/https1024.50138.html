太离谱了！据 Consensys 法务主管向媒体披露，一名疑似朝鲜黑客通过长期合作的人力供应商，以外包人员身份进入 MetaMask 团队，参与法币出入金功能开发约一个月。
安全系统发现其 IP 和行为异常后，公司立即撤销全部权限、暂停相关产品发布，并启动内部调查。目前暂未发现实质性数据泄露或资金损失。其 GitHub 记录显示，今年 3 至 4 月曾多次向 MetaMask 提交代码。
