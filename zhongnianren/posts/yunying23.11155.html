《静态住宅 IP 教程 · 第二篇》
——Clash Verge（最新版）链式代理设置指南
上一篇我们讲了手机端 Shadowrocket 如何设置“静态住宅 IP”。
这篇来讲 电脑端 Clash Verge 的配置方法：同样简单、同样稳、同样适合养号。
很多人用 Clash 却不知道：
最稳的做法，是链式代理：先机场，再住宅 IP。
出口走住宅，既安全又不跳 IP。
以下是完整教程👇
⸻
🍥 第 1 步：把你的住宅 IP 添加到节点里
你在购买住宅 IP 后，会拿到：
•IP
•端口
•用户名
•密码
打开 Clash Verge 最新版 → 左侧点击 “代理”
在节点区域里手动添加（或导入）你的：
Residential-IP（Socks5 或 HTTPS）
写入后，它会出现在你的节点列表中。
⸻
🔗 第 2 步：开启“链式代理模式”
右上角找到：
「链式代理」按钮（Chain Proxy）」 → 开启
这是关键！
链式代理的逻辑是：
先连机场节点 → 再通过住宅节点 → 再出去访问网络
看到的出口 IP = 住宅 IP
机场只是用于传输加速。
⸻
🧩 第 3 步：配置节点顺序
在右侧的“代理链配置”里：
1️⃣ 先点击一个你的 机场节点（如 新加坡 / 香港）
它会出现在列表里，显示为第 1 个。
2️⃣ 再点击你刚写入的 Residential-IP
它会出现在列表里，显示为第 2 个。
顺序必须是：
① 机场节点 → ② 住宅节点
（顺序错了会无法连通）
如图中所示。
⸻
▶️ 第 4 步：点击连接，等待片刻
点击“连接”。
⚠️ 注意：
住宅 IP 延迟比机场高一些，所以：
👉 它会慢几秒连上
👉 状态变绿表示成功
👉 访问 Google / X 测试是否正常
连上后，你现在的电脑已经在：
✔ 出口使用住宅 IP
✔ 稳定不跳 IP
✔ 适配养号 & 安全操作
非常稳。
⸻
📌 使用技巧 & 注意点
1. 链式代理保证稳定性（最重要）
单独用住宅 IP = 延迟高、容易断
链式代理 = 稳定加速 + 出口纯净
2. 住宅 IP 不适合日常高速任务
它更适合：
•养号
•稳定登陆
•不跳 IP 的使用场景
撸毛 / 大流量操作建议继续用机场。
3. 节点顺序不能反
顺序必须是：
机场 → 住宅
不是住宅 → 机场！
