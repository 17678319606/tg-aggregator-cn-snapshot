Stripe CEO 有可能是最懂 personal agent 的。
现有的各种商业公司，很多都依赖用户知道的信息不足、用户的注意力和理性不足来赚钱。
比如保险公司的附加销售、4S 店、网络信贷等，这些都是因为用户知道的信息不足，结果多付出了很多成本。用户多付出的成本，变成了公司的利润。
比如各种广告、排行榜、还有 GEO、以及各种 SaaS 和 AI 产品的订阅制等，都利用了用户的注意力和理性不足。用户很容易被第一眼或反复看到的信息影响，很难理性花足量时间去分析思考后再决策。这里面用户多付出了很多成本，比如为公司承担了广告费，比如支付了根本没用的订阅费等。
以上一切，大量存在，但未必合理。personal agent 有可能让商业世界发生巨大变化。
personal agent 最强悍的地方，就是看起来像人，实际上一点都不像人。最不像人的地方，就是 agent 可以获取并处理大量信息、可以长时间专注一件事、可以非常理性做决策。
一句概括是：personal agent 有机会，站在用户角度，让用户的人性弱点不被商业公司利用。
比如买保险，agent 可以帮你一眼识破条款里的冤枉钱。比如网络购物，agent 可以根据你的喜好，而不是广告排行，去帮你选到最适合你的商品。比如订阅软件，agent 可以在你不用时，自动帮你取消，让大量依赖健身房逻辑的 AI 产品倒闭，等等。
这样，对所有商业公司来说，最重要的是回归到最朴素的商业竞争：把产品做好。
在 personal agent 的世界里，终于有机会，酿酒师可以专心酿酒，公司可以专注于产品创新和产品品质。酒香真不怕巷子深了。
一切看起来很美好。美好之前，有两个关键问要解决：
1、agent 的信息来源。除了旧世界里已被污染的各种信息，是否有机会有新的信息来源，比如 Stripe 开放真实交易数据供 agent 获取和辅助决策。
2、personal agent 能站在用户这边。用户要信任 agent，敢授权。agent 也要信任用户，能始终站在用户角度、代表用户利益去获取信息和推理决策。这可能是 personal agent 创业公司的机会。
personal agent 的核心不是懂用户，而是能真正站在用户角度去思考决策，能代表用户利益去和世界相处。
