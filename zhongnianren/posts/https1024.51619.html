推荐一个纯粹好用的开源工具：沃逸 Markdown 编译器。
在 AI 时代，无论是在 Prompt 编写、Agent 设定还是 Skill 构建中，Markdown（.md）都已成为最核心的文本格式。它对人类易读易写，对 AI 而言解析成本极低。
日常处理 Markdown 文本时常遇到痛点：Office 套件无法直接打开，基础文本编辑器缺乏实时预览，网页版小工具数据安全性难以保障，而 Obsidian 等产品则更偏向重度知识管理。
为了解决这些问，开发者“冷逸”推出了这款开源免费的 Markdown 编辑工具 —— 沃逸 Markdown 编译器（GitHub 项目名：lengyi-markdown-editor）。
1️⃣ 开箱即用，极轻量化：体积仅约 250KB，无需安装复杂的依赖包，直接在浏览器中打开即可开始编写与预览。
2️⃣ 双栏实时预览：采用经典的“左侧编辑、右侧实时渲染”界面，所见即所得。
3️⃣ 完全本地化，数据安全：所有文档编辑与处理均在本地浏览器内完成，不上传服务器，保障数据隐秘性。
4️⃣ 灵活导入与导出：支持自由拖拽导入文档，并提供多种格式的导出选项。
5️⃣ 丰富编辑工具栏：内置常用的格式化按钮（标、加粗、斜体、列表、代码块等），并支持 Mermaid 图表语法渲染，方便快速绘制流程图与结构图。
如果你日常需要频繁处理 Prompt 词库、AI 配置文件或编写技术文档，需要一款简单、安全、响应极快的编辑工具，可以在 GitHub 搜索并使用 woyin2024/lengyi-markdown-editor。
