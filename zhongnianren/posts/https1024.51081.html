想租 GPU 跑模型，看了几家平台，价格差得还不少，到底哪个价才算正常？
Computable GPU Index 是一个开源的 GPU 价格指数工具，会把多家平台的公开报价整理成 GPU 云算力价格 参考指数。目前可以看 H100 SXM、H200 SXM、B200 和 B300，每 15 分钟更新一次。
租 GPU 前可以先看看现在的市场价，拿到供应商报价后也能顺手对一下，做训练预算时心里更有数。
它的计算方法、历史数据和代码都公开，还提供 REST API 和 MCP，Claude 这类支持 MCP 的 AI 客户端也能直接查最新价格。
