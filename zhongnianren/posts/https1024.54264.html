Windows 必备的10 个工具APP。
它们刚好覆盖文件搜索、截图、传文件、卸载、播放、修图、知识管理、远程访问、多机协同和自动化。
1. Everything：快速搜索电脑里的文件，文件数量再多也能迅速定位。
2. PixPin：免费截图工具，支持长截图、OCR、贴图和像素级截图，功能远超系统自带截图。
3. LocalSend：Windows、Mac、Android、iPhone 之间互传文件，局域网直连，不用注册账号。
4. Geek Uninstaller：卸载程序时连注册表和残留文件一起清理，适合处理卸载不干净的软件。
5. PotPlayer：本地视频播放器，格式、字幕和编码支持都很全面。
6. Upscayl：开源 AI 图片高清化工具，适合放大模糊老照片和低分辨率图片。
7. Obsidian：不只是笔记软件。知识库、双向链接、白板和插件生态都很强，适合搭建个人知识系统。
8. Tailscale：把电脑、NAS、服务器组成虚拟局域网，远程访问家里设备更方便。
9. Deskflow：一套键盘鼠标控制多台 Windows、Mac、Linux 设备，适合多设备办公。
10. VS Code + AI Agent：即使不懂编程，也可以用 Codex、Kilo Code 等工具协助写脚本、批量处理文件和做自动化。
这 10 款不一定适合所有人，但覆盖的都是 Windows 用户经常遇到的高频场景。
