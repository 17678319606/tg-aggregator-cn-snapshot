Sub2API
一个把 AI 订阅额度做成可管理 API 网关的开源项目
→ 这不是普通中转壳子，是自托管的“AI 配额分发后台”。
→ 它把多账号调度、API Key 分发、Token 级计费、并发限速这些脏活一次补齐了。
→ 如果你在做团队共享、拼车分摊、统一上游出口，这项目确实值得点开。
→ 连 OpenAI Responses 兼容细节和 Claude Code 已知问都写了，明显是踩过坑的人在做。
→ 代价也很明确：要 PostgreSQL + Redis，定位不是轻量脚本，而是能长期跑的管理系统。
